Why use it

Fewer clicks for teachers, more clarity for students

Today, bringing an EduPlay video into Moodle usually means downloading the file, uploading it again and hoping it works in H5P. The suite replaces that with pasting a link.

🔗

Paste the link, get the player

The normal video page link becomes the official EduPlay player, with captions, speed control and fullscreen.

🔍

Find it by title

Search in the Moodle file picker and see thumbnails, without leaving the page or hunting for addresses.

🎯

H5P and Interactive Video

Add questions, hotspots and quizzes on top of EduPlay videos, something these plugins do not accept on their own.

💾

Nothing is copied

The video stays on EduPlay: no storage cost, no duplicate files, always the current version.

♿

Accessible and responsive

16:9 on any screen, titles for screen readers, keyboard use and no autoplay. Checked with axe-core.

🛡️

You stay in control

Only genuine EduPlay links become a player, and one setting turns off every request to the service.

Installation

Install in a few minutes

Each plugin is installed like any other Moodle plugin, from the release ZIP.

  1. Download local_eduplay from Releases. It is the core and the others depend on it.
  2. Choose what to use: media_eduplay (player), tiny_eduplay (editor button) and repository_eduplay (search). Each has its own ZIP.
  3. Install at Site administration > Plugins > Install plugins, finish the upgrade and purge the caches.
  4. Done. Paste an EduPlay link in any text, in Interactive Video or in the H5P editor.

Requirements: Moodle 4.5 LTS or 5.3 LTS. Current state: beta (pre-release). Search and metadata use the public EduPlay API, which is not documented and may change; pasted links keep working if it does.

moodle-local_eduplay

The core plugin of the suite: validates EduPlay URLs, builds the canonical, embed and H5P URLs, queries the public API (search and metadata, cached) and accepts the canonical link in Interactive Video and in the H5P editor.
