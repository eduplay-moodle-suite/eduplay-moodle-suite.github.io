🎬 Módulos, Filtros e Editores

Extensões desenvolvidas para proporcionar uma experiência fluida de reprodução e incorporação de conteúdos audiovisuais do EduPlay.

📺

moodle-mod_eduplay

Módulo de atividade que permite adicionar vídeos e transmissões ao vivo do EduPlay como recursos avaliativos ou formativos no curso, com rastreamento de conclusão.

Moodle 4.x+ Atividade Streaming PHP
Ver Repositório
⚡

moodle-filter_eduplay

Filtro que transforma automaticamente links e códigos de vídeos do EduPlay inseridos em qualquer texto do Moodle em reprodutores de vídeo responsivos e acessíveis.

Moodle 4.x+ Filtro de Texto Auto-embed PHP
Ver Repositório
✍️

moodle-tiny_eduplay

Extensão para o editor TinyMCE que adiciona um botão dedicado na barra de ferramentas para buscar e embutir vídeos do EduPlay diretamente no conteúdo editorial.

Moodle 4.1+ TinyMCE 6 Editor JavaScript
Ver Repositório
📁

moodle-repository_eduplay

Repositório para o seletor de arquivos do Moodle (File Picker) que possibilita navegar e referenciar conteúdos do acervo EduPlay com autenticação segura.

Moodle 4.x+ Repositório File Picker PHP
